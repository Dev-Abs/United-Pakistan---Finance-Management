# Mobile design source of truth

- `PRODUCT_AUDIT.md` — users, entities, workflows, APIs, constraints, and priorities.
- `MOBILE_STRATEGY.md` — information architecture, navigation, mapping, and interaction principles.
- `overview/` — visual direction and design-system board.
- `screens/` — representative high-fidelity application screens.
- `workflows/` — detailed high-value transaction flows.
- `states/` — loading, empty, error, offline, permission, and success treatments.

Generated boards are product-direction artifacts. Exact text is implemented as native Flutter text for accessibility and localization; image-rendered text is illustrative.
