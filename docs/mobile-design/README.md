# Mobile design source of truth

- `PRODUCT_AUDIT.md` — users, entities, workflows, APIs, constraints, and priorities.
- `MOBILE_STRATEGY.md` — information architecture, navigation, mapping, and interaction principles.
- `overview/` — visual direction and design-system board.
- `screens/` — representative high-fidelity application screens.
- `workflows/` — detailed high-value transaction flows.
- `states/` — loading, empty, error, offline, permission, and success treatments.
- `v2/core-screens-gradient.png` — gradient-led login, dashboard, members, and member-profile direction.
- `v2/finance-navigation-gradient.png` — activity, reports, Special Fund, and full More drawer direction.
- `v2/ai-management-copilot.png` — dedicated AI home, command chat, message review, and bulk-personalization direction.
- `v2/states-and-forms-gradient.png` — loading, empty, offline, permission, payment, expense, confirmation, and receipt states.

Generated boards are product-direction artifacts. Exact text is implemented as native Flutter text for accessibility and localization; image-rendered text is illustrative.

The `v2/` boards supersede the earlier restrained/flat visual direction. Production UI uses gradients for hierarchy and atmosphere while keeping form fields and long-form content on solid, high-contrast surfaces.
