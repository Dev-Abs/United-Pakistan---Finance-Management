# Workspace continuity

Before working on any request in this repository, read `PROJECT_CONTEXT.md` in full.

After completing each user request, update `PROJECT_CONTEXT.md` with:

- the current product goal and relevant decisions;
- the files/features changed;
- verification performed and its result;
- any deployment steps, open risks, or next actions.

Keep the context concise and current. Replace stale status rather than appending an unbounded transcript. Never store secrets, tokens, passwords, personal financial records, or other sensitive values in the context file.
